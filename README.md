# 💉딱맞닥 · 병원 진료 예약 관리 시스템🏥

증상을 입력하면 진료과를 추천하고, 의사 진료 시간표를 바탕으로 바로 예약할 수 있는 웹 서비스입니다.  
데이터베이스 프로그래밍 과목 팀프로젝트 입니다.

## ✨주요 기능

- 회원가입·로그인, 마이페이지
- 진료과·의사 검색, 증상 기반 진료과 추천
- 진료 예약(예약 가능 시간 계산, 중복 방지), 예약 변경·취소
- 진료기록 조회
- 관리자: 오늘 예약 현황, 진료 스케줄 관리

## 🛠️기술 스택

JSP · Bootstrap · Servlet(MVC) · Java · MyBatis · Oracle
